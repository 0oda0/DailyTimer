# DailyTimer

Единая панель на один экран: **почта**, **расписание из личного кабинета вуза**, **GitHub**, **подписки и чеки**,
погода, календари, новости — и **план на день от ИИ, который работает прямо на твоём сервере без ключей**.

## Что умеет

| Модуль | Что делает |
|---|---|
| 📧 Gmail | Каждые 15 мин разбирает почту: категория, важность, ждёт ли ответа, суть в одном предложении. **Убирает рекламу, рассылки и неважное** из «Входящих» (в архив, не удаляет). **Все чеки собирает в ярлык `DT/Receipts`** и ведёт журнал трат за месяц. **Проверяет «Спам»** и возвращает важное во «Входящие» (ярлык `DT/Rescued`). Сверху панели — краткая сводка и блоки «Ждут ответа», «Важное», «Вытащено из спама». |
| 🎓 Расписание | **Сам входит в личный кабинет по логину и паролю** через встроенный браузер (Playwright), понимает двухшаговый вход (SSO/Keycloak), запоминает сессию и раз в N часов забирает пары. Текст страницы разбирает ИИ, без него — эвристики. Также ICS-ссылка или ручная таблица. |
| 🐙 GitHub | Ждут ревью, назначено на меня, мои PR, уведомления. |
| 💳 Подписки | Находит сами по чекам (Spotify, Яндекс Плюс, ChatGPT, Apple, Steam…), дата следующего списания, предупреждение за 3 дня. |
| 🤖 ИИ | **Без ключей**: локальная модель через Ollama на том же сервере (подбирается под RAM). Если она не ответила — бесплатное облако без ключа. Если и оно не ответило — план по правилам. |
| 📲 Telegram | Утром присылает план дня, днём — срочные письма и письма, которые ждут ответа. |
| ➕ Ещё | Погода (Open-Meteo), любые календари по ICS (Google/Яндекс/Outlook/Apple), RSS-ленты (Хабр и т.п.), контесты Codeforces. |

## Установка на VPS

```bash
git clone -b mishka/hopeful-johnson-s64aid https://github.com/0oda0/DailyTimer.git && cd DailyTimer
bash install.sh
```

Скрипт поставит Docker, найдёт свободный порт, подберёт модель ИИ под память сервера, скачает её,
сгенерирует пароль панели и выведет адрес. Дальше: панель → «Подключения» → вписать данные → «Сохранить».

Память под ИИ: 2 ГБ RAM → `qwen2.5:1.5b`, 4 ГБ → `qwen2.5:3b`, 7 ГБ → `gemma3:4b`, 12 ГБ → `qwen2.5:7b`.
Модель работает на процессоре: план дня пишется 1–3 минуты в фоне — это нормально.

## Где без «пароля приложения» не обойтись

Это ограничения самих сервисов, их не обойти:

- **Gmail** — обычный пароль Google сторонним программам не даёт. Один раз: https://myaccount.google.com/apppasswords
- **GitHub** — API не принимает пароль, нужен токен (в настройках есть ссылка с уже выбранными правами).
- **Telegram-бот** — токен от @BotFather.

Все пароли и токены хранятся в базе зашифрованными.

## Что ещё можно подключить

| Сервис | Как | Что даст |
|---|---|---|
| Яндекс Почта / Mail.ru / Outlook | IMAP + пароль приложения — тот же модуль, что для Gmail | Вторая почта в той же сводке |
| Google Календарь | Секретная ICS-ссылка — **уже работает** через «Другие календари» | События рядом с парами |
| Telegram (личные чаты) | Вход по номеру и коду (Telethon) | Непрочитанные чаты и «ждут ответа» в сводке |
| ВКонтакте | Токен VK ID | Сообщения, беседы группы, мероприятия |
| Moodle / LMS вуза | Логин и пароль, Moodle Web Services API | Дедлайны заданий и оценки — в план |
| Todoist / TickTick / Notion | Токен API | Личные задачи в план дня |
| GitLab | Токен | То же, что GitHub |
| LeetCode / Codeforces | Ник, без пароля | Контесты (Codeforces уже есть), daily-задача |
| Steam / Spotify | Ник / OAuth | Статистика, подписки |
| Банки (Т-Банк и др.) | Уведомления о списаниях приходят на почту и разбираются как чеки | Расходы без доступа к банку |
| Погода, курсы валют, праздники | Открытые API без ключей | Утренний контекст |

## Локально

```bash
pip install -r requirements.txt && playwright install chromium
python -m dailytimer          # http://127.0.0.1:8080
python -m pytest              # тесты
```

Переменные окружения: `DAILYTIMER_USER`, `DAILYTIMER_PASSWORD` (вход в панель), `DAILYTIMER_PORT`, `DAILYTIMER_HOST`,
`DAILYTIMER_DATA`, `DAILYTIMER_SECRET_KEY`, `OLLAMA_URL`, `OLLAMA_MODEL`, `CHROMIUM_PATH`.
