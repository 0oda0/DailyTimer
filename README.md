# DailyTimer

Единая панель на один экран: **GitHub**, **Gmail с автосортировкой**, **расписание университета**,
**подписки** и **план на день от бесплатного ИИ**, который каждое утро собирается сам из всех подключённых сервисов.

## Что умеет

| Модуль | Что делает |
|---|---|
| Gmail | Каждые 15 мин читает свежие письма, раскладывает по категориям (важное, учёба, разработка, финансы, подписки, рассылки, реклама, соцсети) и вешает ярлыки `DT/*` прямо в Gmail. Может убирать рекламу из «Входящих». |
| GitHub | Запросы на ревью, назначенные задачи, твои открытые PR, уведомления. |
| Расписание | ICS/webcal-ссылка вуза (с логином/паролем, если нужен) или ручная таблица с чёт/нечёт неделями. |
| Подписки | Находит сами по чекам в почте (Spotify, Яндекс Плюс, ChatGPT, Apple, Steam и др.), считает дату следующего списания, предупреждает за 3 дня. |
| ИИ-план | Утром (по умолчанию в 07:00) синхронизирует всё и пишет план дня: главное, блоки времени вокруг пар, ответы на письма, деньги. Без ключа ИИ строит план по правилам. |

Бесплатный ИИ на выбор: **Gemini 2.5 Flash** (рекомендую, ключ — https://aistudio.google.com/apikey),
**Groq / Llama 3.3 70B**, бесплатные модели **OpenRouter** или локальная **Ollama**.

## Про «просто логин и пароль»

Всё вводится один раз в веб-форме, дальше система работает сама. Но два сервиса **по обычному паролю сторонние программы не пускают** — это их политика безопасности, обойти её нельзя:

- **Gmail** → нужен *пароль приложения*: https://myaccount.google.com/apppasswords (1 минута, нужна 2FA).
- **GitHub** → нужен *токен*: в настройках есть готовая ссылка с правильными правами.

Все пароли и ключи хранятся в базе зашифрованными (Fernet).

## Установка на VPS

```bash
git clone https://github.com/0oda0/DailyTimer.git && cd DailyTimer
bash install.sh
```

Скрипт поставит Docker, найдёт свободный порт (8080, 8088, 8090, …), сгенерирует пароль панели и выведет адрес.
Дальше открой панель → «Подключения» → вставь данные → «Сохранить».

## Локально

```bash
pip install -r requirements.txt
python -m dailytimer          # http://127.0.0.1:8080
python -m pytest              # тесты
```

Переменные окружения: `DAILYTIMER_USER`, `DAILYTIMER_PASSWORD` (вход в панель), `DAILYTIMER_PORT`,
`DAILYTIMER_HOST`, `DAILYTIMER_DATA` (папка с базой), `DAILYTIMER_SECRET_KEY` (ключ шифрования).
