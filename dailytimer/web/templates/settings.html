🎓 Расписание — личный кабинет

Вставь адрес кабинета, логин и пароль. Система сама войдёт через встроенный браузер, откроет страницу расписания и вытащит пары (каждые N часов).

🐙 GitHub

GitHub не даёт входить в API по паролю. Создай токен (права уже выбраны по ссылке), срок — «No expiration».

🤖 ИИ — без ключей

Модель работает прямо на твоём сервере (Ollama) — бесплатно, без ключей и лимитов, почта никуда не уходит. Если локальная не ответит — запасной бесплатный облачный вариант без ключа.
